# Recto resources

Every icon and graphic the app ships. All files are generated by `design/tools/build_resources.py` from the colour tokens in `design/tokens/colors.json`; do not edit the PNG or ICO files by hand. See [`preview.png`](preview.png) for everything on one sheet.

Interface glyphs (toolbar, menus, settings) are not here: they come from the Segoe Fluent Icons system font (see `design/SPEC.md` section 6).

Every size in the ICO files is a hand-picked rendering (the small variant at 24 px and below), not a downscale of the 256 px image.

## Where the PNGs go

Copy `msix/Assets/` into the app project's `Assets/` folder and reference the base names in `Package.appxmanifest`; Windows picks the right scale and target size by itself.

| Base name | Sizes generated | Content |
|---|---|---|
| `Square44x44Logo` | scale 100 to 400 (44 to 176 px); targetsize 16, 20, 24, 30, 32, 36, 40, 48, 60, 64, 72, 80, 96, 256, each plain, `_altform-unplated` (dark taskbar, with edge) and `_altform-lightunplated` | App icon, full bleed |
| `Square71x71Logo` | scale 100 to 400 | Icon at 62% |
| `Square150x150Logo` | scale 100 to 400 | Icon at 50% |
| `Wide310x150Logo` | scale 100 to 400 | Icon at 50% of the height, centred |
| `Square310x310Logo` | scale 100 to 400 | Icon at 50% |
| `StoreLogo` | scale 100 to 400 (50 to 200 px) | App icon, full bleed |
| `SplashScreen` | scale 100 to 400 (620 × 300 to 2480 × 1200) | Dark lockup on transparent; set the splash background to `#1B1A19` |
| `FileTypes/PdfFile` | targetsize 16 to 256 | PDF file-type icon |

Tiles carry the icon only, no text, so they work on any tile background.

```xml
<Properties>
  <DisplayName>Recto</DisplayName>
  <Logo>Assets\StoreLogo.png</Logo>
</Properties>

<uap:VisualElements DisplayName="Recto" Description="Read, convert and organize PDFs."
    BackgroundColor="transparent"
    Square150x150Logo="Assets\Square150x150Logo.png" Square44x44Logo="Assets\Square44x44Logo.png">
  <uap:DefaultTile Wide310x150Logo="Assets\Wide310x150Logo.png"
      Square71x71Logo="Assets\Square71x71Logo.png" Square310x310Logo="Assets\Square310x310Logo.png" />
  <uap:SplashScreen Image="Assets\SplashScreen.png" BackgroundColor="#1B1A19" />
</uap:VisualElements>

<Extensions>
  <uap:Extension Category="windows.fileTypeAssociation">
    <uap:FileTypeAssociation Name="pdf">
      <uap:DisplayName>PDF document</uap:DisplayName>
      <uap:Logo>Assets\FileTypes\PdfFile.png</uap:Logo>
      <uap:InfoTip>Open with Recto</uap:InfoTip>
      <uap:SupportedFileTypes>
        <uap:FileType ContentType="application/pdf">.pdf</uap:FileType>
      </uap:SupportedFileTypes>
    </uap:FileTypeAssociation>
  </uap:Extension>
</Extensions>
```

Windows only uses Recto's file-type icon for `.pdf` files when Recto is the user's default PDF app.

## In-app graphics

Load the SVGs with `SvgImageSource`. Pick the light or dark file through theme resources so the image follows the app theme, for example `RectoDropFilesImage` defined in the Light and Dark theme dictionaries pointing at `drop-files-light.svg` and `drop-files-dark.svg`.

## Rebuilding

From the repository root:

```
python design/tools/build_resources.py --newsreader <path to Newsreader[opsz,wght].ttf>
```

Needs Python with fontTools and Pillow, and Edge or Chrome for rasterising. The Newsreader variable font is under the SIL Open Font License 1.1 and is available from the Google Fonts repository (`ofl/newsreader`). The wordmark and the "PDF" badge are converted to outlines, so the app never ships either font.
