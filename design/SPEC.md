# Recto design specification

Status: approved direction "D · Merged", 2026-10-13; revised 2026-10-21 by owner decision (icons, no icon tiles, the shape system, the Sheet app icon and generated brand graphics); revised 2026-10-22 by owner decision: Recto draws this design with its own toolkit `recto-ui` instead of WinUI 3, and the design itself is unchanged. Owner of decisions: the project owner. Review again after the first runnable shell (milestone M2).

This file is the source of truth for how Recto looks and behaves. When a screenshot and this text disagree, this text wins. When a screen has no D screenshot, build it from the reference listed for it and apply the tokens in section 4.

Architecture, threading and milestones live in `docs/plans/2026-10-13-recto-foundation.md`. This spec covers the interface only.

## 2. Principles

1. The page is the product. Chrome stays quiet, low-contrast and out of the page area; the accent appears only where the user acts or where they are.
2. One app shell. Every layout preset uses the same controls in different places (section 8).
3. Native first. Use the `recto-ui` controls, which reproduce the Fluent (WinUI 3) controls this spec was written against, and Windows behaviours (Mica, caption buttons, snap layouts, system dialogs for files and printing) unless this spec says otherwise. Design: `docs/specs/2026-10-22-recto-ui-toolkit-design.md`.
4. Honest conversion. Say what a conversion is good at and what it is not (PDF to Word works best on text documents).
5. Safe by default. Links and Office macros never run without the user's say-so.

## 3. Brand

### 3.1 App icon

Direction A "Sheet": the icon is the shape itself, with no tile behind it. One white page with a soft paper gradient, a hairline edge so it holds on light backgrounds, a soft drop shadow at 48 px and larger, and the vermilion bookmark ribbon hanging from the top edge near the right. The ribbon marks "where you are reading": the same idea as the name (the recto is the right-hand page).

All icon and graphic files are built and live in `resources/` at the repository root; `resources/README.md` lists every file, where it goes in `Package.appxmanifest`, and how to rebuild. `resources/preview.png` shows them all.

| File | Use |
|---|---|
| `resources/svg/app-icon.svg` | Master, 48 px and larger: three text lines on the page and the soft drop shadow. |
| `resources/svg/app-icon-medium.svg` | 32 to 47 px: the same drawing without the shadow and with a firmer page edge, so it holds on a light taskbar. |
| `resources/svg/app-icon-small.svg` | 24 px and smaller (title bar, taskbar, tabs). A separate drawing: darker page outline, no text lines, larger ribbon. |
| `resources/msix/Assets/` | Every package logo at every scale and target size. The `altform-unplated` and `altform-lightunplated` sets use the same art, because there is no tile to remove. |
| `resources/ico/recto.ico` | Window icon (`WM_SETICON` on the `ui::Window`) and unpackaged builds |

There are no on-dark variants: without a tile, the same two files work on light and dark backgrounds. The icon colours (`brand` in `tokens/colors.json`) are fixed and never follow the theme. Reference board: `screenshots/D-Brand.png`.

### 3.2 PDF file-type icon

What Explorer shows for `.pdf` files when Recto is the default PDF app: a white document with a folded top-right corner, the Recto ribbon hanging from the top edge, three text lines, and a vermilion "PDF" badge overlapping the bottom-left edge. At 24 px and below the lines and badge are dropped and the outline gets heavier. Files: `resources/svg/filetype-pdf.svg`, `resources/svg/filetype-pdf-small.svg`, `resources/msix/Assets/FileTypes/PdfFile.targetsize-*.png` (manifest `uap:Logo` of the `.pdf` file-type association) and `resources/ico/pdf-file.ico`.

The "PDF" badge uses the light accent `#C8431F` (`brand.fileTypeBadge`) on every background, while the ribbon uses the brand ribbon colours of the app icon (`brand.iconRibbon*`), so the ribbon matches the app icon and the badge matches the accent.

### 3.3 Wordmark

"Recto" set in **Newsreader Medium** at the 72 pt optical size (Google Fonts, SIL Open Font License 1.1). Used only for the wordmark: the title bar name, About, the Store listing, the banner and the social preview. Letter spacing -1 at 48 px and above. The app uses the outlined SVGs (`resources/svg/wordmark-*.svg`, `lockup-*.svg`) and the brand graphics draw the same outlined glyphs, so nothing ships or loads the font. Tagline, when used: "the right-hand page", Newsreader Italic.

### 3.4 In-app graphics

`resources/svg/` also holds the Settings layout preset wireframes (`layout-*-light.svg` and `-dark.svg`), the Home empty-state and drop-overlay illustration (`drop-files-*.svg`) and the current-page ribbon marker (`ribbon-marker*.svg`). Load them with `ui::SvgImage` and switch light and dark files through `ui::ThemeManager`. Interface glyphs are not graphics: they come from the `RectoIcons.ttf` icon font (section 6). Only the app icon (3.1) and the file-type icon (3.2) are pictures of a thing; every other glyph follows section 6.

### 3.5 GitHub banner and social preview

`brand/github-banner.png` (1280×320, for the top of the README) and `brand/github-social-preview.png` (1280×640, set in the repository settings) are generated by `tools/build_resources.py` from the tokens; never draw or edit them by hand. Both are dark: charcoal background, the ribbon hanging from the top edge, the Sheet app icon (3.1), the wordmark drawn from outlined Newsreader glyphs, the line "Open-source PDF viewer and converter for Windows", the chips "PDF to Word", "Merge and split" and "Office to PDF" (pill shape, section 7), and `github.com/rizonesoft/Recto`. They name no third-party engine or licence and carry no placeholder text.

### 3.6 Installer images

`tools/build_resources.py` also generates the Inno Setup wizard images from the tokens and the app icon: `resources/installer/wizard-image-<scale>.png` and `resources/installer/wizard-small-<scale>.png` for the scales 100, 125, 150, 175, 200, 225 and 250, sized to Inno Setup's image areas with the default font: the large image keeps the 164:314 aspect ratio at 202×386, 269×515, 336×643, 403×772, 430×824, 498×953 and 534×1022, and the small image is square at 58, 77, 97, 116, 124, 143 and 159 px (the areas follow font metrics, so 200 percent is not double 100 percent). The installer script names each set as a comma-separated list in `WizardImageFile` and `WizardSmallImageFile`, so Setup picks the image that matches the display scale.

High contrast: the generated tokens map every Recto brush to a system colour in high contrast themes. Never hide information behind colour alone.

**Pages in dark theme** (a setting): Original (pages render as authored), Dimmed (default: pages are multiplied towards `#D9D5CE`, as in `D-Focus-Dark.png`) and Inverted (light text on `#1B1A19`; images are not inverted). This changes how tiles are composited, not the PDF.

The mockup boards for screens other than the viewers show light theme only. Build their dark versions by swapping tokens; `D-Focus-Dark.png` and `D-ReadingRoom.png` show how surfaces, borders and the accent behave in dark.

Interface: **Segoe UI Variable** through the `recto-ui` type ramp, which reproduces the WinUI type ramp. Documents are never restyled; page text is whatever the PDF contains.

| Role | Style (WinUI ramp name) | Size / weight | Where |
|---|---|---|---|

| Body | `BodyTextBlockStyle` | 14 / Regular | Default text |
| Body strong | `BodyStrongTextBlockStyle` | 14 / Semibold | Row titles, selected items |
| Subtitle | `SubtitleTextBlockStyle` | 20 / Semibold | Dialog titles, card headings |
| Title | `TitleTextBlockStyle` | 28 / Semibold | Page titles (Settings, Organize) |

## 6. Icons

Every Recto interface glyph comes from **Fluent UI System Icons** (Microsoft, MIT licence), npm package `@fluentui/svg-icons` pinned at `1.1.344`. Segoe Fluent Icons and Segoe MDL2 Assets are not used for Recto glyphs.

- Designs: only the 20 px designs, drawn at 16, 20 and 24 epx. Regular by default; Filled for a toggled or selected state.
- Delivery: a subset icon font, `resources/fonts/RectoIcons.ttf`, built from the pinned SVGs at build time by `scripts/build-icon-font.py`. It holds the glyphs in the table below and the custom glyphs, nothing else. Controls draw them with `ui::Icon` from the `RectoIcons` font; never a system icon font code point for a Recto glyph, nor a per-glyph SVG or PNG.
- Built-in control glyphs: `recto-ui` controls draw their built-in glyphs (caption buttons, `ComboBox` chevrons, check marks, spinner and scrollbar arrows) from Segoe Fluent Icons, exactly as WinUI's stock controls do. Do not swap a built-in control glyph for a Recto glyph.
- Custom glyphs: allowed only where the set has none (today: Redact and Squiggly underline). Draw them on the 20 px grid in the Fluent style, with a Regular and a Filled form, and add them to `RectoIcons.ttf`. Each one is a row in the table marked custom. Acceptance: Regular strokes are 1 px on the 20 px grid with round caps and joins, outer corners 1 to 2 px radius, the shape stays inside the 2 to 18 px live area, horizontal and vertical edges land on whole pixels, the Filled form keeps the Regular outline, and the glyph is reviewed beside its nearest table neighbours (Highlight and Strikeout for Redact, Underline for Squiggly) at 16, 20 and 24 epx before it ships.
- Cloud providers: the OneDrive, Google Drive, Dropbox, Box and SharePoint marks use each provider's own artwork under its brand rules, never a font glyph. The generic cloud concept uses `cloud`.
- Colour: a glyph is drawn in `RectoTextSecondaryBrush` by default, `RectoTextBrush` on hover, and `RectoAccentBrush` on the selected row or a toggled state.
- No icon tiles: no interface glyph sits inside a filled or tinted box, tile or circle, anywhere (command box rows, Home, Convert cards, dialogs, lists, settings). Selection is shown by the row's `RectoAccentTintBrush` background and the accent glyph; alerts by a 24 epx glyph in the status colour (9.9). A toggled button's own background (8.2) is the control's state, not a tile. Only the app icon (3.1) and the file-type icon (3.2) are pictures.
- Sizes: 16 epx in toolbars, menus and lists; 20 epx in the navigation rail; 24 epx in dialog headers, alerts and Convert option cards.

The stroke icons in the mockups are placeholders that show which concept goes where; the table names the glyph. A concept missing from the table gets a row before any control uses it.

## 7. Shape, spacing and elevation

- Spacing follows a 4 epx grid. Common gaps: 4, 8, 12, 16, 24, 32.
- Corner radius has three values, all from the generated tokens, never a literal:
  - 4 epx (`ControlCornerRadius`): every control: buttons (the floating toolbar's buttons and the accent Convert button included), inputs, dropdowns, segmented controls, toggle buttons, toolbar buttons, list rows and tabs.
  - 8 epx (`OverlayCornerRadius`): cards, panels, the floating page toolbar and the contextual mode bars, the floating side panel, menus, flyouts, the command box, dialogs, settings groups, the queue card and the page canvas.
  - Full pill (radius = half the height), style `RectoChipStyle`: only chips and filter tags, shortcut keycaps, status badges and counters.
- Document pages and page thumbnails stay square.
- Elevation (shadows) only on floating things: the floating toolbar, floating panels, the command box, menus, dialogs and the queue card. Docked panes have borders, not shadows. Use the `recto-ui` elevation, which reproduces WinUI's `ThemeShadow`, at Z 32 for the toolbar and panels and Z 64 for dialogs and the command box.
- Document pages sit on the canvas with a soft shadow (1 epx key, 24 epx ambient) and square corners.
- Window minimum size: 960 × 600 epx. Below 1100 epx wide, floating panels close when the user clicks the page.

## 8. App shell and layout presets

One `ShellPage` hosts the same controls in every preset. A `LayoutSettings` view model holds five settings; the shell moves controls between named slots when a setting changes. Changing any single setting turns the preset name to "Custom". Reference: `screenshots/D-Layout.png`.

| Setting | Focus (default) | Classic | Reading room |
|---|---|---|---|
| Page toolbar | Floating, bottom centre | Docked command bar, top | Docked strip under the tabs |
| Side panels | Floating cards over the canvas | Docked left pane | Docked right inspector |
| Page thumbnails | In the left panel | In the left pane | Filmstrip along the bottom |
| Search and outline | Left | Left | Right |
| Navigation (Home, Convert, Organize) | Title bar tabs plus command box | Left navigation rail | Mode switcher in the title bar |
| Screenshot | `D-Focus-Light.png`, `D-Focus-Dark.png` | `D-Classic.png` | `D-ReadingRoom.png` |

Slots: title bar, top bar, bottom overlay, left dock, right dock, left overlay, right overlay, bottom dock. `ThumbnailList` switches its `ui::ItemsView` layout between a vertical stack and a horizontal stack when it moves between the left panel and the filmstrip.

### 8.1 Title bar (all presets)

Left to right: small icon (20 epx), wordmark "Recto" (Newsreader, 17 epx), Home tab (icon only), one tab per open document (`ui::TabStrip`, max 240 epx, close button on hover and on the active tab), new tab (+), the command box button centred in the remaining space ("Search, open or run a command", shows "Ctrl K"), settings, then the system caption buttons. The title bar is draggable everywhere except on interactive elements. In Reading room the mode switcher (Home, Read, Convert, Organize, underline indicator in accent) replaces the Home tab and document tabs move to the strip below.

### 8.2 Floating page toolbar (Focus) and contextual mode bars

A single row on `RectoRaisedBrush`, radius 8 (section 7), 48 epx tall (36 epx buttons, section 11, inside 6 epx padding), centred 22 epx above the bottom of the canvas. Order: side panel toggle | previous page, "3 / 9" (click to type a page), next page | zoom out, zoom % (click for presets: fit width, fit page, 50 to 400%), zoom in, fit width | find, rotate, annotate/tools toggle, print | **Convert** (accent button) | more (save a copy, page layout, two-page view, page colour, form designer, redact & sanitize, sign document, compare PDFs, extract tables/images, crop & page setup, watermark & header/footer, optimize PDF, properties). Toggled buttons use `RectoAccentTintBrush` with accent-coloured Filled glyphs (section 6). The toolbar fades to 40% opacity after 3 s without pointer movement while reading and returns on hover or keyboard focus; it never hides completely.

When the user activates an authoring or inspection tool from the toolbar, side panel or `Ctrl+K`, a compact **contextual mode bar** (same `RectoRaisedBrush`, radius 8, 48 epx tall with 36 epx buttons inside 6 epx padding, docked directly above the floating toolbar in Focus or below the top command bar in Classic/Reading room; `Esc` closes it) appears:

1. **Markup & Annotation Bar (`Ctrl+Shift+A`):** Text markup tools (`Highlight`, `Underline`, `StrikeOut`, `Squiggly`), `Sticky Note`, `FreeText` (text box and callout with leader line), `Ink` (freehand pen and eraser), `Shapes` (rectangle, ellipse, line, arrow, polygon, polyline), `Stamp` picker (`Approved`, `Confidential`, `Draft`, `Final`, `Void`, custom text/image stamp), `Attachment Pin`, `Link` region tool, a style popover (colour swatch tokens, opacity slider, stroke width, font size), `Undo` / `Redo`, and `Flatten`. Selected annotations on the page show 8-point resize/move handles on the canvas.
2. **Form Fill & Form Designer Bar:** Interactive AcroForm (and XFA-converted) fields are fillable directly on the page canvas at all times (text boxes, checkboxes, radio buttons, combo boxes, list boxes, push buttons, signature fields, with tab-order keyboard navigation and required-field indicators). Toggling **Edit Form** opens the Form Designer bar: place new fields (`Text Field`, `Checkbox`, `Radio Button`, `Dropdown`, `List Box`, `Button`, `Signature Box`) by dragging on the page, align/resize handles, a Field Properties flyout (field name, tooltip, default value, font, read-only/required flags, calculation order), `Import Data` / `Export Data` (`JSON`, `XFDF`, `FDF`, `XML`), `Reset Form`, and `Flatten Form`.
3. **Redaction & Sanitize Bar (`Ctrl+Shift+X`):** `Mark Text / Area` tool (drag over text quads or rectangular regions to create redaction marks outlined in `RectoDangerBrush`), `Redaction Appearance` popover (fill colour and optional overlay code text such as `[REDACTED]` or FOIA exemption codes), `Preview Redacted` toggle, **`Apply Redactions`** (accent danger button that writes a new copy with underlying glyphs, vector paths, and clipped image pixels permanently stripped from content streams), and **`Sanitize Document`** (opens the Sanitize dialog to strip hidden metadata, XMP, embedded files, scripts, actions, and incremental history).
4. **Table & Image Extractor Bar:** `Select Table Region` tool (auto-detects tables on the page or lets the user draw/adjust a table bounding box and column/row dividers on the canvas), opens a live bottom preview drawer showing extracted cells, with `Export to Excel (.xlsx)`, `Export to CSV`, `Copy Table`, and `Extract Page Images`.
5. **Signature Banner & Sign Mode (`Ctrl+Shift+G`):** When a PDF contains digital signatures, a quiet status banner appears at the top of the canvas (`RectoSurfaceBrush` with `RectoSuccessBrush`, `RectoWarningBrush` or `RectoDangerBrush` badge: "Signed and all signatures are valid", "Signed with unsigned changes after signing", or "Signature verification failed") with `View Signatures` and `Sign`. Activating **Sign Document** prompts the user to drag a signature rectangle on the page (or choose an invisible signature) and opens the Sign Document dialog (section 9.9).

### 8.3 Floating side panel (Focus) and docked panels

A card 16 epx from the canvas edges, radius 8, `RectoRaisedBrush` at 90% opacity with acrylic where available. Header row: panel name, panel switcher menu, panel-specific action button, close (`Ctrl+B`). All panels share the same control instances across Focus (floating card), Classic (left dock) and Reading room (right inspector):

## 11. Accessibility

- Every control is reachable by keyboard in a logical order: title bar, menu bar (Classic), toolbar, active mode bar, side panel, page (including interactive form fields and annotations in reading/tab order), status bar (Classic).
- Focus uses the Fluent focus visual (as WinUI draws it) in the accent colour.
- Icon-only buttons have an automation name and a tooltip with the shortcut.
- Page text, interactive form fields, and tagged PDF structure (`/StructTreeRoot` when present) are exposed through UI Automation providers (plan milestone M3) so screen readers can read, navigate headings/tables, fill forms, and select text.
- Hit targets are at least 32 × 32 epx (36 in the floating toolbar and mode bars).
- Respect "Show animations in Windows"; when off, the toolbar does not fade and panels appear without motion.
- Colour is never the only signal: selected pages also get a check badge, signature states and errors also get an icon and text.

## 12. Motion

Panels and cards: fade and translate 8 epx over 167 ms with the standard Fluent easing. Dialogs: the Fluent `ContentDialog` open and close motion. Page turns: none; scrolling is continuous. Zoom: animated scale of existing tiles, then sharp tiles replace them (no flash).

This rewrites `mockups/html/` and `screenshots/` using headless Edge (or Chrome). Add `--no-png` to rebuild only the HTML. Fonts load from Google Fonts, so the machine needs internet access for the Newsreader wordmark to render.

To rebuild the icons and graphics in `resources/` (including the installer images) and the brand graphics in `brand/` after changing a token or a shape, run `python design/tools/build_resources.py --newsreader <path to Newsreader[opsz,wght].ttf>` (details in `resources/README.md`). The icon font `resources/fonts/RectoIcons.ttf` is built from the pinned `@fluentui/svg-icons` SVGs and the custom glyphs by `python scripts/build-icon-font.py` (section 6).
