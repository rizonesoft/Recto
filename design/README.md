# Recto design

Everything needed to build Recto's interface, without access to the original design canvas.

Start with [`SPEC.md`](SPEC.md). It is the source of truth and points to a screenshot for every screen and state.

| Folder | Contents |
|---|---|
| [`screenshots/`](screenshots/) | The chosen design (`D-*.png`) and the explorations it came from (`explorations/`) |
| [`tokens/`](tokens/) | Colours as JSON, the source of the generated `recto-ui` tokens (`scripts/build-ui-tokens.py`) |
| [`brand/`](brand/) | GitHub README banner and social preview, generated by `tools/build_resources.py` (never drawn by hand) |
| [`../resources/`](../resources/) | Every icon and graphic the app ships (app icon, PDF file-type icon, wordmark, MSIX PNGs, ICO files, in-app graphics, Inno Setup wizard images, and the `RectoIcons.ttf` icon font) |
| [`mockups/html/`](mockups/html/) | Static HTML of every screen, for measuring in a browser |
| [`mockups/source/`](mockups/source/) | Canvas sources, used to regenerate the HTML and screenshots |
| [`tools/`](tools/) | `render-mockups.mjs` (screenshots) and `build_resources.py` (icons, graphics, brand PNGs and installer images) |

## Generated graphics and icons

- `tools/build_resources.py` builds everything in `../resources/` and `brand/` from `tokens/colors.json`: the Sheet app icon (`app-icon.svg` and `app-icon-small.svg`; no on-dark variants), the file-type icon, the wordmark and lockups, the MSIX assets, the ICO files, the in-app graphics, the Inno Setup wizard images (`resources/installer/wizard-image-<scale>.png` and `wizard-small-<scale>.png`, scales 100 to 250) and the two brand PNGs (`brand/github-banner.png`, 1280x320, and `brand/github-social-preview.png`, 1280x640). SPEC sections 3.1 to 3.6 describe each one.
- Interface glyphs are Fluent UI System Icons (`@fluentui/svg-icons` 1.1.344, MIT), shipped as the subset font `resources/fonts/RectoIcons.ttf` that `scripts/build-icon-font.py` builds at build time. SPEC section 6 maps every concept to its glyph; no glyph sits in a filled or tinted tile.

The application architecture is in [`docs/plans/2026-10-13-recto-foundation.md`](../docs/plans/2026-10-13-recto-foundation.md).
