Recto: foundation plan

Status: draft for implementation. Written 2026-10-13. Review again at the end of milestone M1.

Recto is an open-source PDF viewer and converter for Windows, written in C and C++ with a WinUI 3 interface. This plan records every decision made so far, the architecture, the MuPDF thread-safety setup, and the milestones to version 1.

1. Decisions

#DecisionChoice
D1Product nameRecto, the right-hand page of an open book
D2LicenseAGPL-3.0-or-later, open source from the first public commit
D3PDF engineMuPDF, pinned to a release tag
D4UIWinUI 3 on Windows App SDK 2.4.0, C++/WinRT
D5LanguagesC17 for the bridge, C++20 for everything else
D6DistributionMSIX through the Microsoft Store
D7v1 conversionsImages, text, merge, split, Office to PDF, PDF to Word
D8TargetWindows 11, x64 and ARM64
