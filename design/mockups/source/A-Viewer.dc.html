3. Architecture

3.1 Modules

The rule behind the module table: dependencies point one way only, recto-pdf to recto-core to recto-services to the app. Every module is Recto's own C++20, and every parser returns PdfResult values instead of throwing.

recto-cli exists so the engine can be tested, profiled and fuzz-reproduced without the UI.
