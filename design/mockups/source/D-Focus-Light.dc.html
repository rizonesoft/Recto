3. Solution Structure

3.1 Modules and Dependency Rule

Dependencies flow strictly downward. No upward includes, no friend hacks, no XAML headers below src/app.

Recto (src/app) uses recto-services (src/services), which uses recto-core (src/core), which uses recto-pdf (src/pdf). Two additional executables link against recto-core and recto-pdf (never src/app): recto-cli and recto-tests.
