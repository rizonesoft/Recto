4.6 Opening and viewing a document

1. The UI calls Runtime::open(path). This starts a DocumentActor thread, which clones the base context and calls fz_open_document.

2. If fz_needs_password is true, the actor reports it; the UI asks for the password and posts it back.

3. The actor reports page count, page sizes and the outline to the UI.

4. For each page the viewport needs, the actor builds an fz_display_list and hands a kept reference to the render scheduler.
