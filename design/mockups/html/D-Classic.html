3. Solution Structure

3.1 Modules and Dependency Rule

Dependencies flow strictly downward. No upward includes, no friend hacks, no recto-ui headers in the engine libraries. Two additional executables link against recto-core and recto-pdf (never src/app): recto-cli and recto-tests.

3.2 Repository Layout

Recto/ |-- Recto.sln |-- src/ | |-- pdf/ # recto-pdf (C++23 static lib) | |-- core/ # recto-core (C++23 static lib) | |-- services/ # recto-services (C++23 static lib) | |-- cli/ # recto-cli (C++23 console app) | |-- mcp/ # recto-mcp (C++23 console app) | |-- printer/ # Recto PDF v4 printer driver package | |-- ui/ # recto-ui (C++23 static lib) | \-- app/ # Recto (Win32 desktop app) |-- tests/ |-- fuzz/ \-- installer/ # Inno Setup script and installer assets
