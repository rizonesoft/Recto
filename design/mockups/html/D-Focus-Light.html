3. Architecture

3.1 Modules

The rule behind the module table: only recto-bridge includes MuPDF headers. Everything above it sees Recto's own types. This keeps setjmp and longjmp error handling out of C++ and lets the bridge move into a separate sandbox process later.

recto-cli exists so the engine can be tested, profiled and fuzz-reproduced without the UI.
