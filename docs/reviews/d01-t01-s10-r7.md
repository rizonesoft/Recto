## Findings

1. **major: Action-alias cache duplicates URI payloads outside the link budget** (`src/pdf/document.cpp:2979`)
   - **Evidence:** Each reference in `hop_refs` receives a separate `CachedActionSummary` copy, including owning `uri` and `action_type` strings, which are excluded from `total_link_bytes`. A 476,692-byte PDF containing 300 links, each with 31 distinct aliases leading to one shared 6 KiB URI action, opened with 143,269,888 bytes of working-set growth (vs 16,293,888 bytes for the direct-reference control).
   - **Required fix:** Share one immutable `std::shared_ptr<const CachedActionSummary>` across aliases, consult cached targets during alias resolution, and account for cache storage before insertion. Add a regression covering distinct alias chains converging on a shared action.

2. **major: Shared resource dictionaries are retained separately for every explicit page reference** (`src/pdf/document.cpp:1496`, `src/pdf/document.cpp:1521`)
   - **Evidence:** Each explicit `/Resources` reference is resolved and copied into a new `std::shared_ptr<const PdfDict>`. Inherited-resource sharing does not deduplicate identical explicit indirect `/Resources` references across pages. A 163,457-byte PDF containing 1,024 pages referencing one `/Resources` dictionary with a 64 KiB font payload opened with 482,738,176 bytes of working-set growth.
   - **Required fix:** Cache and share resolved indirect `/Resources` dictionaries by object identity (including aliases), and bound aggregate retained resource storage (`estimate_pdf_value_bytes`) before copying. Preserve whole-dictionary replacement semantics and add a repeated-reference regression across distinct pages.

3. **minor: XMP stream-limit failures are silently discarded** (`src/pdf/document.cpp:1867`)
   - **Evidence:** When `decode_stream(*meta_stm, kMaxMetadataStreamBytes)` fails with `ErrorCode::DecompressionLimitExceeded` (or `ErrorCode::OutOfMemory`), the error is silently ignored instead of propagating the limit rejection.
   - **Required fix:** Propagate `DecompressionLimitExceeded` / `OutOfMemory` from `/Catalog /Metadata` XMP stream decoding and add an oversized-XMP regression test alongside metadata/outline/font budget boundary tests.
