## Fixes for round 3 (implementing session)

Round 2 re-reported round 1 because its prompt named the old commit (see the note above). Round 3 reviewed ac6da59 and found three more ways to hide an include from a text scan: a macro operand, a UTF-8 BOM and a raw string literal. Fixed in the next commit: `#include MACRO` is refused outright inside the guarded modules, the BOM is dropped before lexing, and raw string bodies are opaque to the comment stripper; each shape is planted in `Ui.Project.IncludeBoundary`. Decision: the text scan is the second wall. The first wall is the build itself (`recto-ui` has no engine directory on its include path and the engine projects have no `src/ui` one), so a scan bypass is not an architecture breach; further preprocessor-level evasions (for example `__has_include` tricks) are not chased and are recorded here as accepted P3 residue.
