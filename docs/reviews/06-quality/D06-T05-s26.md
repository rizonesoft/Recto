## source-defect: needs-attention

5. **P1, `scripts/build-corpus.py:2640`: JPEG quantization tables are never validated.** Starting with `make_minimal_jpeg_8x8_rgb()`, replace its complete DQT segment with `FF DB 00 02`. The actual seed validator accepts this image with no quantization table defined, although its frame references table 0. Required table contents are specified in [T.81 §B.2.4.1](https://www.w3.org/Graphics/JPEG/itu-t81.pdf).

6. **P1, `scripts/build-corpus.py:2637`: JPEG scan component identities are ignored.** Change the first SOS component selector to `99`, leaving the frame’s component identifiers as `1, 2, 3`. The seed passes because only the component count is checked, and the decoding loop discards component identifiers. This violates the scan-to-frame association in [T.81 §B.2.3](https://www.w3.org/Graphics/JPEG/itu-t81.pdf).

7. **P1, `scripts/build-corpus.py:2628`: invalid JPEG Huffman code spaces are accepted.** In the generated JPEG’s first DHT table, change the length-one count from `1` to `2`, append another symbol, and adjust the segment length. The seed still passes with a defined all-ones code. The canonical-code construction lacks the required validity check. [T.81 Annex C](https://www.w3.org/Graphics/JPEG/itu-t81.pdf) reserves that code.

8. **P1, `scripts/build-corpus.py:2709`: JPX COD and QCD are checked only for marker presence.** Replace either complete generated segment with `FF 52 00 02` or `FF 5C 00 02`. Both malformed seeds pass. The engine explicitly rejects these lengths at `src/pdf/filters.cpp:7497` and `:7779`; the missing parameters are required by [T.800 §§A.6.1 and A.6.4](https://www.itu.int/rec/dologin_pub.asp?id=T-REC-T.800-201511-S%21%21PDF-E&lang=f&type=items).

9. **P1, `scripts/build-corpus.py:2708`: JPX packet data is never validated.** Replace everything between SOD and EOC with `FF FF`, and set Psot to `16`. The seed passes. The validator checks only the enclosing length and nonempty payload, so malformed packet data survives independently of the header defects above.
