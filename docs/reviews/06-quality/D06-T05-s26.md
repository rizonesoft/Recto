## Decoder inventory

Every decoder `scripts/build-corpus.py`'s validators call, the ISO 32000-1 clause it follows, and the engine function in `src/pdf/filters.cpp` whose refusals it matches. None reads a generator function to decide what is correct.

| Decoder | Clause | Engine | Refuses |
| ------- | ------ | ------ | ------- |
| `inflate` | 7.4.4 | `decode_flate` | malformed or truncated data, bytes after the stream, output past 4 MiB |
| `inflate_bounded` (deflate bomb only) | 7.4.4 | `decode_flate` | output past the ceiling (counts only; the inner bomb is never inflated to its end) |
| `flate_png_up_decompress` | 7.4.4.4 | `apply_predictor` | partial or no rows, any row tag but Up (2), the only one the corpus writes |
| `lzw_decode_pdf` | 7.4.4.2 | `decode_lzw` | no initial clear, a code past the table, a full table, no EOD, data after EOD |
| `ascii85_decode_pdf` | 7.4.3 | `decode_ascii85` | characters outside `!`..`u`, `z` in a group, groups of 2**32 or more, a one-character final group, data after `~>` |
| `asciihex_decode_pdf` | 7.4.2 | `decode_ascii_hex` | non-hex characters, a missing `>`, data after it |
| `rle_decode_pdf` | 7.4.5 | `decode_run_length` | runs past the data, a missing EOD, data after EOD |
| `ccitt_g4_decode` | 7.4.6 (ITU-T T.6) | `decode_ccitt_fax` | unknown mode or run codes, changing elements out of order or past the line, too few lines, a missing EOFB, data after it; the image must be the documented 16x16 picture |
| `validate_jbig2_embedded` | 7.4.7 (ISO/IEC 14492 7.2) | `decode_jbig2` | segments other than page information, generic region (MMR, decoded by `ccitt_g4_decode`) and end of page; wrong sizes; data lengths that do not fit |
| `validate_jpeg_baseline` | 7.4.8 (ITU-T T.81) | `decode_dct` | missing SOI, DQT, SOF0, DHT, SOS or EOI; a frame of another size; a scan that is not exactly the frame's MCUs padded with 1 bits; data after EOI |
| `validate_jpx_codestream` | 7.4.9 (ISO/IEC 15444-1 Annex A) | `decode_jpx` | SIZ other than one 8-bit component of the stated size, missing COD or QCD, a tile-part whose Psot does not span SOT to EOC, data after EOC |

The CCITT code tables cover run lengths 0 to 16 (every corpus CCITT image is 16 pixels wide) and match `src/pdf/filters.cpp`'s `kCcittWhiteCodes` and `kCcittBlackCodes` entry for entry.
