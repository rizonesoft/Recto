## Per-surface choices

Recto converts Office files with its own engines and depends on neither Office nor LibreOffice (D5, D7, D10), so no surface that installs or chooses between them survives. Each was replaced with what `design/SPEC.md` shows in its place:

| Board | Old surface | Choice | Source |
| ----- | ----------- | ------ | ------ |
| `A-Dialogs` | "Office to PDF needs Microsoft Office or LibreOffice" with install links | Replaced by "Apply redactions and sanitize?" in the board's own dialog style | SPEC 9.9 (its dialog set has no Office-install dialog; this is its destructive-operation confirm, as `D-Dialogs` shows) |
| `B-Dialogs` | The same dialog | Replaced the same way | SPEC 9.9 |
| `C-Dialogs` | "Install Office or LibreOffice" | Replaced the same way | SPEC 9.9 |
| `A-Settings` | "Office to PDF converter: Found Microsoft Office. LibreOffice not installed." | "Default Office to PDF page setup", value "Match original document" | SPEC 9.7, Converting group |
| `C-Settings` | The same row | Replaced the same way | SPEC 9.7 |

Each new dialog follows SPEC 9.9: a warning glyph in the warning colour with no tile behind it, title, text, the summary of what is removed, and the buttons "Apply and save copy" and "Cancel". (`D06 T05 §25` had already reworded the Office readiness banner and the waiting jobs on `A-Convert` and `B-Convert`.)
