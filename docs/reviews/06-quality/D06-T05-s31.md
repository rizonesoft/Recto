## Self-review (implementing session, before the completion review)

- Striped pages (T.88 7.4.8.2, 7.4.10): a page of height `0xFFFFFFFF` starts at its maximum stripe size and grows (`Jbig2DecoderState::grow_page_to`) as regions and End-of-Stripe segments reach further, each growth charged to the JBIG2 budget and refused past the ceiling; the last End-of-Stripe fixes the final height. A page of known height is unchanged (regions outside it are clipped as before).
- MMR halftone planes (T.88 6.2.6): each MMR invocation ends on a byte boundary, so the next plane starts at the next byte. The `Jbig2Decode` fixture concatenated unaligned planes and is corrected (its first plane padded from 38 to 40 bits).
- HENABLESKIP (T.88 6.6.5.1): an arithmetic halftone with the flag builds HSKIP from the grid geometry and decodes each gray-scale bitplane with it (USESKIP in the generic decoder: a skipped pixel is 0 and not decoded); the mask is charged with the bitplanes. MMR halftones must have the flag clear and ignore it.
- Retained contexts (T.88 7.4.2.2): flag bit 9 keeps a symbol dictionary's generic and refinement statistics (charged to the budget); flag bit 8 starts from the last referred-to dictionary's, refused when none retained or the template differs.
- Failure modes (`AGENTS.md`): every new allocation (page growth, skip mask, retained contexts) is charged to the existing JBIG2 budget; malformed uses (contexts no dictionary retained, a template mismatch) are refused with `DamagedFormat`.
- Tests that fail before the change: `PdfFilters.Jbig2StripesAlignmentAndSkip` on `716eaa5` (one row instead of two; the aligned planes refused), and each later part with its own fix removed (without the skip mask the region reads `00 0F 00 0F` instead of `0F 0F 0F 0F`; without the restored contexts dictionary B decodes more symbols than it declares).
