## Findings

1. **`major` — Destination alias-cache allocations escape the memory budget (`src/pdf/document.cpp:2393, 2424, 2620`):**
   `parsed_dest_obj_cache` retains a separate `ParsedDest` entry for every alias hop without charging an aggregate budget, whereas `total_named_dest_bytes` accounts only for entries in `named_dests_`.
2. **`medium` — Cached resolution bypasses the indirect-reference depth limit (`src/pdf/document.cpp:1528`):**
   `resolve_indirect_chain_with_cache` returns a cache hit before checking depth, and cached entries carry no remaining-chain length. A resource chain containing 32 aliases followed by its terminal dictionary opens when an earlier page has cached the terminal, fails when encountered first, and still fails through `resolve_object()` after opening.
3. **`medium` — New regression assertions do not establish all Round 8 claims (`tests/recto-tests/pdf_document_tests.cpp:683, 719`):**
   The compressed/commented resource-alias test checks successful opening and font inventory without an assertion that detects duplicate parsing or retained allocations (`page_resources(0).get() == page_resources(1).get()`), and the resource-generation test checks only the final deduplicated font count instead of asserting each page's `page_resources(i)` for stale-first and valid-first cases.
4. **`minor` — Font deduplication loses `has_differences` (`src/pdf/document.cpp:3607`):**
   Duplicate `FontSummary` entries merge `has_to_unicode` (`existing.has_to_unicode = existing.has_to_unicode || summary.has_to_unicode`) but omit `existing.has_differences = existing.has_differences || summary.has_differences`.
