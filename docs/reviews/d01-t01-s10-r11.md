Per W3C XML Namespaces section 3, only the reserved `xml` prefix (`http://www.w3.org/XML/1998/namespace`) identifies `xml:lang`.

   `XmlScope` copies `prefix_ns` per element and linearly scans all bindings on each `xmlns:<prefix>` attribute across 9 separate property scans. Use $O(1)$ scoped namespace storage in a single pass with bounded work and add an adversarial regression test.
