## Findings

1. **P2 (`src/pdf/display_list.cpp:624`): Stroke bounds exclude painted ink.**
   - `draw_path()` accumulates centerline geometry without stroke width, caps, joins, or miter expansion.
   - **Fix:** Compute transformed stroke-outline geometry using the active stroke style (`line_width`, `line_cap`, `line_join`, `miter_limit`), clip against active clip paths, and union with fill bounds. Add tests for thick strokes, caps, miters, and nonuniform transforms.

2. **P2 (`src/pdf/display_list.cpp:589`): Clip bounding boxes cannot establish exact clipped ink bounds.**
   - Clipping retains only the path's axis-aligned rectangle and ignores polygon geometry and fill rule (`NonZero` vs `EvenOdd`).
   - **Fix:** Retain clip geometry and fill rule on the builder state stack and compute clipped painted bounds using 2D polygon/scanbeam intersection with each active clip path's fill rule. Add tests for nonrectangular clips, even-odd holes, and nested clips.

3. **P2 (`src/pdf/display_list.cpp:672`): Glyph fallback bounds are advance boxes, not ink bounds.**
   - Fallback uses `advance_pt` and `abs(font_size)`, omitting descenders, negative bearings, and overhangs while assigning ink to whitespace glyphs.
   - **Fix:** Carry per-glyph `ink_bounds_pt` / `is_blank` on `PositionedGlyph` (or derive from `local_bounds_pt` / `type3_sub_list->content_bounds_pt()`), rejecting visible runs that lack glyph ink bounds without synthesizing advance-box approximations. Add descender, overhang, and space-only tests.

4. **P2 (`src/pdf/display_list.cpp:538`): Fully transparent operations expand content bounds.**
   - `set_alpha_and_blend` does not update `TrackingState`, and transparent strokes, fills, glyph runs, and images still contribute to `content_bounds_pt`.
   - **Fix:** Track saved/restored `stroke_alpha` and `fill_alpha` in `TrackingState` and exclude operations whose effective alpha (state alpha, command colour alpha, or bitmap/mask pixel alpha) paints no ink. Add transparent-path, glyph, and image tests.

5. **P2 (`src/pdf/display_list.cpp:444`): Builder allocations are unbounded and indices narrow unchecked.**
   - Pool offsets/counts are cast to `uint32_t` without limits, commands grow without a budget, and `std::bad_alloc` can escape.
   - **Fix:** Enforce configurable `DisplayListLimits` (counts, `uint32_t` narrowing bounds, and aggregate byte budget) before allocation, catch `std::bad_alloc` returning `ErrorCode::OutOfMemory`, return `PdfResult<T>` from builder methods, and preserve valid builder state on non-fatal single-call failure. Add configurable small-budget tests.

6. **P2 (`src/pdf/display_list.cpp:449`): Malformed and non-finite geometry can be sealed.**
   - `add_path()` and command recording methods accept truncated/mismatched verb/point sequences, invalid enum values, and NaN/infinite values.
   - **Fix:** Validate verb arity, subpath sequencing, and finiteness of all points, matrices, stroke styles, alphas, colours, and glyph metrics before recording, returning `ErrorCode::DamagedFormat` without partial insertion. Add truncated-path, invalid-verb, NaN, and infinity tests.

7. **P2 (`src/pdf/display_list.h:445`): Public indexed accessors permit undefined behaviour.**
   - `DisplayList::path()`, `path_verbs()`, `path_points()`, `glyphs()`, and `dash_values()` index or slice unchecked.
   - **Fix:** Validate indices and `(offset, count)` ranges with overflow-safe subtraction checks (`offset <= size && count <= size - offset`) and return `PdfResult<...>`. Add boundary tests for every accessor.

8. **P2 (`src/pdf/display_list.cpp:472`): Save-depth overflow silently changes state semantics.**
   - Beyond depth 64, `save_state()` emits commands without saving state, corrupting subsequent bounds after `restore_state()`.
   - **Fix:** Reject excess nesting (and unmatched `restore_state()`) with `PdfResult<void>` error and latch a builder failure state so an overflowed builder cannot publish a corrupted `DisplayList`. Add tests for state changes inside an overflowing frame.

9. **P2 (`src/pdf/display_list.h:229`): Bitmap validation is bypassable through the public constructor.**
   - `DecodedBitmap` has a public constructor allowing callers to bypass `DecodedBitmap::create()`.
   - **Fix:** Make `DecodedBitmap` constructor `private` and add `static_assert` and factory boundary tests.

10. **P3 (`src/pdf/display_list.cpp:730`): Repeated sealing can return empty storage with stale bounds.**
    - After the first `DisplayList` is destroyed, `sealed_result_.lock()` expires and calling `finish()` again constructs an empty `DisplayList` with stale `content_bounds_pt_`.
    - **Fix:** Make `finish()` a strict one-shot operation returning `PdfResult<std::shared_ptr<const DisplayList>>` that fails with `ErrorCode::InternalError` on any subsequent `finish()` call. Add test calling `finish()`, releasing the result, and calling `finish()` again.
