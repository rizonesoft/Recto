   `extract_xmp_tag_value` searches for literal tag/attribute names such as `dc:title` without resolving XML `xmlns` / `xmlns:<prefix>` namespace declarations to their canonical namespace URIs (`http://purl.org/dc/elements/1.1/`, `http://ns.adobe.com/pdf/1.3/`, `http://ns.adobe.com/xap/1.0/`, `http://www.w3.org/1999/02/22-rdf-syntax-ns#`).

   `load_document_structure()` unconditionally replaces `description_.pdf_version` with any valid `/Catalog /Version` entry instead of retaining the higher version when the file header specifies a later PDF version (ISO 32000-1 section 7.5.2 / 7.7.2).
