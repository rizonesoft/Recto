### The cuts

- `/JMC` off in both builds (`CMakeLists.txt` `recto_defaults`, `Directory.Build.targets` `SupportJustMyCode`): it only changes how the debugger steps over code; `/RTC1`, which catches bugs, stays.
- The parser reads each token where the lexer left it (`Lexer::peek_into`, `Lexer::drop_front`) and consumes it at once, the token every path consumed before, instead of moving it out through two `PdfResult<Token>` and peeking through `PdfResult<const Token*>`; `parse_integer_or_ref` takes the integer's value and offset and constructs no `PdfError` per integer. All 209 lexer, parser, serializer, xref, document, filter, interpreter and corpus tests pass; CI `bbaed9a` green on the full matrix.
- `Corpus.RejectsUnlistedOrModifiedFile` copies the corpus once; each case makes its change, is refused, undoes it, and the copy must validate clean again before the next case (a new assertion per case, and one before the first).
- `Runtime.ShutdownUnderActiveTileLoad` loads one cycle of the fills (`held_load_content()`, 180: every position the 2,000 draw at, which repeat every 180). Its compiles are held at their first operator (the interpreter polls before every operator) and its tiles at their first 64-command poll (`rasterizer.cpp` `replay`), so each round holds the same load. `busy_content()` keeps 2,000 for the tests whose compile must keep running.
- `PdfRasterizer.CancelWhileRunning` no longer renders the 400,000-curve path uncancelled after its cancels: that render asserted nothing and is `D01 T02 §19`'s to bound and measure (its item "Bound what one path can hold a worker for inside one Direct2D call" states the figure, 1.9 s then; 3.8 s on this host in Release today). Every cancel and latency assertion stays.
