Require a fixture with fewer horizontal metric records than glyphs; otherwise ordinary subset fonts can receive incorrect advances. See the [OpenType `hmtx` specification](https://learn.microsoft.com/en-us/typography/opentype/spec/hmtx).

This is distinct from the bare CFF work deferred to §29; OpenType CFF has no `glyf` boxes. See the [OpenType metrics specification](https://learn.microsoft.com/en-us/typography/opentype/spec/hmtx).

4. **P1, plan, line 160:** The limits do not bound total expanded outline storage or aggregate composite traversal. A compact font can reuse components across many glyphs and exhaust memory while staying within every listed per-glyph limit. Add cumulative allocation and work budgets enforced before expansion, with fixtures that exceed those budgets while remaining below the individual limits.

5. **P2, plan, lines 158–159:** A single stripped subset does not prove the promised simple and composite outline support. Require fixtures covering both `loca` formats, empty glyphs with nonzero advances, implied on-curve points, transformed composites and point-attached components. Compare geometry against independent expected results, not merely two loads through the same implementation. These are normal TrueType representations described by the [`loca`](https://learn.microsoft.com/en-us/typography/opentype/spec/loca) and [`glyf`](https://learn.microsoft.com/en-us/typography/opentype/spec/glyf) specifications.

6. **P2, plan, lines 149, 157 and 160:** Loader lifecycle and operational failures lack enforceable contracts. Define and inject failures for factory/loader/reference/face creation and allocation, distinguishing font rejection from resource failure before attempting fallback. Also name the expected typed errors: line 160 currently promises “the error code each case names” but names none. Microsoft explicitly assigns [registration and unregistration to the caller](https://learn.microsoft.com/en-us/windows/win32/api/dwrite_3/nf-dwrite_3-idwritefactory5-createinmemoryfontfileloader), and [references remain valid only while registered](https://learn.microsoft.com/en-us/windows/win32/api/dwrite_3/nf-dwrite_3-idwriteinmemoryfontfileloader-createinmemoryfontfilereference).
