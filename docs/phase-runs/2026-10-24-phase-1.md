## Lessons

- 2026-10-24: `Copy-Item` keeps the source file's timestamp, so restoring a mutated source from a saved copy leaves it older than the mutant's objects and the next incremental build of that configuration silently runs the mutant; touch the restored file before the next build.
- 2026-10-24: a sweep for one class of defect has to check what each traversal holds while it waits, not only whether it recurses: the iterative action-chain walker still kept copies of pending siblings alive (round 4).

- 2026-10-24: `build/build.ps1` throws when a test fails, so a mutation run that stashes sources inside the same PowerShell command never reaches its `stash pop`; restore in a separate step (or use `try`/`finally`) and check `git stash list` after every mutation run.
