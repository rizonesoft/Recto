## Lessons

- A reviewer that keeps finding one defect a round in the same file is describing a class, not a list: on `D00 T04 §9` the classes were "one failed read decides more than itself", "a local failure leaves as the exit code that means red" and "a file's existence is taken for ownership". Each stopped being found only when the mechanism changed (each read fails alone; `main()` owns exit 1; an operating system lock), not when the instance was patched.
- Prove a scheduled task by its last run, not its registration: `Get-ScheduledTask` listed all four tasks while none had started for a day.
- A test written to prove a fix found a defect no reviewer had (`Scheduled.test_a_first_poll_that_is_stopped_is_not_the_baseline`): write the neighbouring case, not only the reported one.
