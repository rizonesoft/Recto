## Lessons

- `scripts/campaign_guard.py` previously exempted `review_in_flight` (`build/review-in-flight/`) from `stop_decision` and `heartbeat_still` stall-breaker counting, while an active `scripts/ci_status.py --wait` holding its OS byte-range lock on `build/ci-watch/<sha>.lock` (`ci_status.py --gate` wait before claiming or stamping) was counted as idle stops. Added `ci_watch_in_flight` (probing the OS lock + `exit is None` + 65-minute age bound) and `test_a_live_ci_watch_lets_the_turn_end_without_tripping_the_breaker`.
- When a section's checklist or Test checkpoint explicitly names the pushed candidate's GitHub Actions run (`build.yml` or `plan.yml`), wait for `scripts/ci_status.py --wait` to exit `0` before dispatching `--kind completion` so Astra sees the finished green CI run on the first completion pass without spending an extra reconciliation pass.
- `docs/reconciliation-review-prompt.md` requires in-scope completion and reconciliation gap closures to use the exact `- Implemented:` prefix (whereas plan review uses `- Planned:` and out-of-scope deferrals use `- Filed: DNN TNN §N (...)`).
