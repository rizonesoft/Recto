## Lessons
- 2026-10-23: incremental invalidation (probes, waiting lists, take-backs) keeps producing edge cases under review; when a correct final state exists, compute from it (a second pass) instead of tracking every change toward it.
- 2026-10-23: when review rounds keep finding new spellings that slip past a byte scanner deciding something only the parser knows (here `/Encrypt`), stop patching the scanner and remove the early decision: defer the work until the parser's own result is in, and read what is needed on demand.
- 2026-10-23: commit each logical group with every other dirty path stashed and the plan synced for that group's state; a hook refusal must never let staged files fall into the next commit (it did once, `3d558a7`).
- 2026-10-23: a refusal test must be able to succeed when the check is removed, or it proves nothing: the first JBIG2 context-refusal fixtures had no page, so they failed with "no page bitmap" either way. Build the negative case as the positive case plus the one difference, and run the mutant.
- 2026-10-23: a fixture that exercises skipped work (HENABLESKIP) must make the skipped symbols change the output; the first one passed without the skip mask because the decoder stayed in step by chance.
