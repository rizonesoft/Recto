## Lessons

- Always leave the final `- [ ] Commit:` checkbox unticked before invoking `GPT-6 Astra` review; `python scripts/todo-graph.py stamp` owns ticking that checkbox.
- When toggling `/fsanitize=address` (`-EnableASAN`) on local builds, MSBuild does not automatically invalidate non-instrumented `.obj` and `.lib` files unless a state marker (`build/asan-state-$cfg-$plat.txt`) triggers a clean of stale intermediate artifacts.
- On Windows, directory symlinks and NTFS junctions (`FILE_ATTRIBUTE_REPARSE_POINT`) must be explicitly checked before recursing in corpus and temp-directory walkers.
