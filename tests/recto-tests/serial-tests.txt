# Tests that run in the serial pass, alone, after the parallel shards (D00 T04 section 11).
# One gtest filter pattern per line; '#' starts a comment. build/build.ps1 excludes these from every shard and runs
# them in one process of their own, so a measured latency or wall-clock limit is proven on a host that no sibling
# shard is loading. recto::test::expect_cancel_latency (cancel_test_support.h) and Runtime.ShutdownLatency turn a
# missed limit into a report when other processes use more than half the processors, so beside the shards they would
# stop proving their limit without failing.
