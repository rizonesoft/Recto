# Recto Test Corpus

All deterministic PDF and OpenXML fixtures used by `recto-tests`, `recto-cli`, and the `fuzz_*` libFuzzer targets live under `tests/corpus/`.

Every fixture in this directory is synthetically generated by [`scripts/build-corpus.py`](../../scripts/build-corpus.py) using only the Python standard library, fixed timestamps (`D:20261013000000Z` and `2026-10-13T00:00:00Z`), and deterministic `/ID` digests so re-running the generator produces byte-for-byte identical files across machines.

## Folder Structure

| Folder | Role |
| ------ | ---- |
| `render/` | Rendering, cross-reference (`xref` table, `/Type /XRef`, `/Type /ObjStm`), incremental `/Prev` revision, page rotation (`0`, `90`, `180`, `270`), image/vector (`DCTDecode`, `FlateDecode` + `/SMask`, `CCITTFaxDecode`, `/Form` XObject), and encrypted (`RC4-128`, `AES-128`, `AES-256`) fixtures. |
| `text/` | Reading-order (two-column layout, ligatures `fi`/`fl`, soft hyphens `U+00AD`, hierarchical `/Outlines`, internal `/XYZ` and external `/URI` links) and raster-only scanned OCR (`scanned.pdf`) fixtures. |
| `convert/` | Document conversion and extraction fixtures: bordered orthogonal-line tables, borderless whitespace-aligned tables, `/AcroForm` interactive widgets (`/Tx`, `/Btn`, `/Ch` with `/AP /N` appearances), `/Annots` markup, and minimal OpenXML `.docx` and `.xlsx` packages. |
| `broken/` | Malformed, truncated, cyclic, and hostile inputs (`empty-0b.pdf`, `non-pdf-header.pdf`, `truncated-header.pdf`, `truncated-stream.pdf`, `corrupt-xref-recoverable.pdf`, `cyclic-xref-prev.pdf`, `cyclic-pages-tree.pdf`, `deep-nested-array-70.pdf`, `deflate-bomb-10kb.pdf`) verifying `PdfResult<T>` error handling, linear XRef recovery, recursion caps (`64` levels), and the `256 MB` per-stream decompression ceiling. |
| `seeds/` | Compact (`< 4 KB` each) seed inputs for `fuzz_open`, `fuzz_filters`, and `fuzz_render`: 6 full PDF seeds covering classic `xref`, `/Type /XRef` + `/Type /ObjStm`, filters, `/Outlines` + `/Annots` actions, and content-stream rendering operators, plus 11 selector-prefixed raw filter seeds (`seed-filter-00-flate.bin` through `seed-filter-0a-chain-a85-flate.bin` starting with selector byte `0x00..0x0A` followed by raw encoded payload). |

## Encrypted Fixture Passwords

All encrypted fixtures under `tests/corpus/render/` use the Standard Security Handler with fixed test passwords and explicit permission bitmask `/P -1028` (`0xFFFFFBFC`):

- **User password:** `recto-test`
- **Owner password:** `recto-owner`
- `render/encrypted-rc4-128.pdf`: PDF 1.7 Standard Security Handler `V=2, R=3` (`128-bit RC4`).
- `render/encrypted-aes-128.pdf`: PDF 1.7 Standard Security Handler `V=4, R=4` (`128-bit AES-CBC`, `/CFM /AESV2`).
- `render/encrypted-aes-256.pdf`: PDF 2.0 Standard Security Handler `V=5, R=6` (`256-bit AES-CBC`, `/CFM /AESV3`, ISO 32000-2 section 7.6.4 Algorithm 2.B iterative hash and `/Perms` ECB block verification).

## Regeneration and Verification

```powershell
python scripts/build-corpus.py          # atomically regenerate all corpus fixtures
python scripts/build-corpus.py --check  # verify on-disk bytes and structure without writing
```

## Provenance Rule

Every file under `tests/corpus/` (except `README.md` and `PROVENANCE.md`) must be registered in [`PROVENANCE.md`](PROVENANCE.md) with its relative path, 64-character lowercase hex SHA-256 digest, `CC0-1.0` license, generator origin (`scripts/build-corpus.py`), and purpose description.

The `Corpus.Provenance` test in `tests/recto-tests/corpus_tests.cpp` walks `tests/corpus/` recursively and fails immediately if any file is unlisted, missing on disk, missing a license, or has a SHA-256 mismatch.

## Golden Refresh Discipline

1. Never refresh golden renders to silence an unexplained test failure.
2. Inspect the `_actual.png` and `4x`-amplified `_diff.png` diagnostic images in `build/test-failures/goldens/` for every changed page before accepting a rendering change.
3. Run `python scripts/refresh-goldens.py` (and `python scripts/refresh-goldens.py --check`) so `tests/corpus/render/goldens/manifest.json` and [`PROVENANCE.md`](PROVENANCE.md) are updated deterministically, and commit the golden refresh in a dedicated commit citing the owning `recto-pdf` section and cause.
